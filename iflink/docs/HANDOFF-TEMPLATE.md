# 交接单模板

每个模块交付时填写：完成了什么、怎么运行、接口有没有变、已知问题和测试结果。

**建议读者：**全员

每个模块负责人在交分支时复制本模板，保存为**自己模块目录下的 `HANDOFF.md`**，并把内容贴到 PR 描述里。 不要写儿童姓名、照片、联系方式、真实试用数据。

# QA 清单与验收记录（成员 E 维护）

本目录放成员 E 的测试清单、验收记录和问题跟踪，不放源代码。

## 建议文件

| 文件 | 内容 |
|---|---|
| `ACCEPTANCE.md` | 对照 `docs/PRD.md` 第 15 节验收标准逐项打勾，写明测试日期、设备、浏览器 |
| `CHECKLIST-DEMO.md` | 五个 demo（gesture / shell / cards / emotion / feedback）的人工检查清单 |
| `A11Y.md` | 键盘可达、对比度、字幕、减少动态、静音路径的检查结果 |
| `PRIVACY.md` | 摄像头启停、无外部请求、不写日志/本地存储的核查记录 |
| `BUGS.md` | 已知问题：现象、影响、临时处理、是否计划修 |

## 纪律

- 验收记录只写结果和证据，不写儿童姓名、照片、联系方式、真实试用数据。
- 每个 AI 产出仍要登记到 `docs/AI-REVIEW-LOG.md`，本目录只放测试与验收。
- 21 号整合当天，本目录的清单是「能不能演示」的唯一依据。

# 成员 C 指南：手势情景选择

10 个情景、应对卡、选对/选错、家长推进、心理老师对接和自动测试。

## 2. 核心玩法：不是拖到场景，而是选应对卡

每个情景：

**1.** 展示情景描述 + 插画 + 语音/字幕。

**2.** 可选“挥手翻一翻”，看一句小提示，不直接给答案。

**3.** 出现 2–3 张应对卡，正面朝上。

**4.** 孩子用捏合抓起一张卡，拖到中央“我的选择”区，松开确认。

**5.** 选对：正向反馈 + 解释。

**6.** 选错：卡片回位 + 高亮“更合适的选择” + 解释。

**7.** **不自动下一题**；显示家长控制条：家长确认下一步、再试一次、结束。

**8.** 单次建议 3–5 个情景，10 个是内容库，不强制做满。

### 2.1 语言口径

- 孩子端说“更合适的选择”，不说“正确答案”“你错了”。
- 内部仍记录 `isCorrect` / `isBest` 用于反馈。
- 允许一个情景有多个 `isCorrect`（“也可以”），但只有一个 `isBest`。
- 选错不扣星星、不红叉、不播错误音。
- 安全类情景统一提示“先离开，找信任的大人”。

### 2.2 10 个候选情景

完整列表在 `docs/PRD.md` 第 7.3 节。你负责把它们写进 `content/cards.json`，全部先标 `draft`：

**1.** 妈妈看起来生气了

**2.** 和同学抢同一个玩具

**3.** 想加入同学的游戏

**4.** 同学哭了

**5.** 不小心弄坏同学的东西

**6.** 排队时有人插队

**7.** 被同学起了不喜欢的外号

**8.** 老师正在忙，你想提问

**9.** 家长说“现在不可以”

**10.** 陌生人靠得太近，你觉得不舒服

**这些是候选，不是最终专业内容。** 心理老师审核后才能改为 `reviewed`。

## 7. 任务三：选择状态机与家长控制

### 7.1 给 DSH 的提示

```
请实现 ScenarioGame 状态机，严格按 docs/CONTRACTS.md：
- 状态：showing-scenario → choosing → correct/incorrect → awaiting-parent → finished
- 只用 InputSource 的 move/grab-start/move(grab)/grab-end/flip
- 翻卡：flip 只在光标位于提示卡/情境卡时翻“小提示”
- 抓起：grab-start 在选项卡热区内才拿起
- 拖拽：grab=true 时卡片跟随光标
- 松开：grab-end 时判断卡片是否在“我的选择”区
- 选对：进入 correct，播放正向反馈，然后进入 awaiting-parent
- 选错：进入 incorrect，卡片回位，高亮 bestOptionId，列出 acceptableOptionIds 作为“也可以”，显示 explanation，然后进入 awaiting-parent
- 手丢失：已抓起卡片回位，不判错
- 不自动 next()；next()/retry()/finish() 只能由家长控制条调用
- 向 AdaptiveEngine 上报 `mode: 'scenario'`、attempt、hintUsed、success；不要用时间当难度
- 写测试：选对、选错、家长不确认不跳、retry、finish、手丢失、重复点击
```

### 7.2 家长控制条

- 只有 `phase === 'awaiting-parent'` 时显示。
- 标注“家长”，长按约 1.2 秒才生效，避免孩子误触。
- 按钮：
  - **下一步**：`scenarioGame.next()`。
  - **再试一次**：仅 `state.canRetry === true` 时显示（选错后为 true），调用 `retry()`。
  - **结束练习**：调用 `finish()`。
- 不自动倒计时，不自动跳。
- 在独立 demo 里由你实现家长条；在整合版里由应用壳实现，你只暴露状态和方法。

## 13. 出问题怎么办

| 现象 | 你做什么 |
|---|---|
| 卡片拖不动 | 让 DSH 检查 `grab-start`/`move`/`grab-end` 顺序 |
| 投放总是不中 | 让 DSH 检查选择区热区和卡片中心判定 |
| 选完自动跳了 | 让 DSH 检查是否在 `awaiting-parent` 前调用了 `next()` |
| 家长按钮短按就生效 | 让 DSH 加长按 1.2 秒和进度反馈 |
| 选错显示红叉 | 让 DSH 改成“更合适的选择”高亮 + 解释 |
| 手丢失后卡死 | 让 DSH 检查 `hand-lost` 是否回位 |
| 内容改了不生效 | 让 DSH 检查 JSON 加载和缓存 |
| 平板溢出 | 让 DSH 截图并调响应式 |
| DSH 改到别人目录 | 立即撤回 |
| 心理老师没回复 | 用 `draft` 内容先跑通，不要自己改成 `reviewed` |

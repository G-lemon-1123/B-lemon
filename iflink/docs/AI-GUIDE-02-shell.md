# 成员 B 指南：应用壳与家长流程

首页、授权、家长角、设置、自适应、家长控制条，以及用 mock 跑通完整空壳。

**建议读者：**成员 B

这份指南只给成员 B。你不需要会写代码；你负责： **让 DSH 做出一个能跑的空壳、亲眼看流程、把分支交上来。** 你的模块不碰摄像头模型，也不做情景选择和情绪识别本身。

## 1. 你的角色与边界

### 1.1 你负责

| 工作 | 说明 |
|---|---|
| 应用壳 | 首页、路由、页面切换、加载态、错误态 |
| 首次说明 | 家长说明、摄像头授权入口、拒绝后的替代入口 |
| 家长角 | 长按进入、设置、清除记录、隐私说明 |
| 设置 | 声音、语音、摄像头预览、减少动态、表情开关、支持等级 |
| 本地存储 | 只存设置、星星、表情卡、支持等级 |
| 自适应引擎 | 接收情景/情绪上报，输出支持等级 |
| 家长控制条 | 每次作答后显示“下一步/再试一次/结束”，长按确认，不自动跳转 |
| Mock 组合 | 没有真实模块时，用 mock 让整个壳跑起来 |
| 独立 demo | `/demo/shell.html` |

### 1.2 你不负责

- 摄像头、手部识别、面部识别。
- 10 个情景的内容和正确性判断。
- 答案卡选择/拖拽规则（成员 C）。
- 表情匹配算法。
- 音效/语音的具体实现。
- 心理老师的专业内容。

## 5. 任务二：首次家长说明和授权入口

### 5.1 给 DSH 的提示

```
请实现首次进入流程：
1. 儿童友好欢迎页：产品名、短说明、“和大人一起，一次一小步”。
2. 家长说明页：
   - 摄像头只在进入手势/情绪页时申请；
   - 画面只在本设备处理，不录像、不上传；
   - 可随时关闭摄像头；
   - 可用鼠标/触摸替代；
   - 不是诊断/治疗工具；

4. 只有点击“开始摄像头”才允许后续调用摄像头；应用壳本身不要直接调用 getUserMedia。
5. 拒绝/失败时显示温和提示，并保留鼠标继续入口。
文案要短、清楚、适合家长阅读，不要吓人。
```

## 6. 任务三：家长角和设置

### 6.1 给 DSH 的提示

```
请实现家长角：
- 入口在主页底部，长按约 2 秒进入，避免孩子误触。
- 设置项：

```

### 6.2 本地存储建议

只存这些：

```

进度：完成情景数量、星星、已解锁表情卡、完成次数、最后使用日期
```

不要存：

- 原始画面
- 人脸/手部关键点
- 姓名、联系方式、学校
- 任何可识别身份的信息

## 7. 任务四：自适应引擎

### 7.1 给 DSH 的提示

```
请实现 src/shared/adaptive/ 的 AdaptiveEngine，严格按 docs/CONTRACTS.md：
- 支持等级：0 多提示、1 标准、2 少提示。
- record(sample)：记录 mode（scenario/emotion）/success/attempts/hintUsed/quality。
- 连续 2 次失败：向 0 调整一级。
- 连续 3 次成功且少用提示：向 2 调整一级。
- 一次只调整一级。
- 不做倒计时，不用时间作为难度。
- setManualLevel(level | 'auto') 支持家长锁定。
- subscribe(handler) 通知等级变化。
- reset() 清空。
- 写单元测试覆盖边界、连续失败/成功、手动锁定。
```

### 7.2 你要检查

☐ 连续失败后，家长端看到“多提示”。

☐ 连续成功后，逐步变成“少提示”。

☐ 一次只变一级，不会突然跳两级。

☐ 家长手动锁定后不再自动变。

☐ 没有“得分”“能力值”等表述。

## 7.3 任务四补充：家长控制条

### 给 DSH 的提示

```
请实现情景练习的家长控制条，严格按 docs/CONTRACTS.md 的 ScenarioGame：
- 订阅 scenarioGame.subscribe(state)，只在 state.phase === 'awaiting-parent' 时显示。
- 标注“家长”，避免孩子误触。
- 按钮：
  - “下一步”：长按约 1.2 秒才调用 scenarioGame.next()
  - “再试一次”：仅 state.canRetry 时显示，长按后调用 retry()
  - “结束练习”：调用 finish()
- 短按无效，要有按住进度反馈。
- 不自动倒计时，不自动 next()。
- 情景模块没接好时，用 MockScenarioGame 演示三种状态：
  - 选对后等待家长
  - 选错后等待家长
  - 家长确认后下一步
- 应用壳不实现答案卡规则，只显示家长条和调用方法。
```

### 你要检查

☐ 选对/选错后都停在家长控制条，不自动下一题。

☐ 家长不按，页面一直等待。

☐ 短按无效，长按 1.2 秒才生效。

☐ “再试一次”只在选错时出现。

☐ “结束练习”能回到小结/主页。

☐ 孩子不容易误触。

## 12. 出问题怎么办

| 现象 | 你做什么 |
|---|---|
| 页面打不开 | 让 DSH 检查 dev server 端口和路由 |
| 摄像头被提前请求 | 让 DSH 搜索 `getUserMedia`，应用壳里不应该有 |
| 刷新设置丢了 | 让 DSH 检查 localStorage key 和读取时机 |
| 平板溢出 | 让 DSH 加响应式断点，截图给你看 |
| DSH 改到别人目录 | 立即让它撤回 |
| 合并冲突 | 只处理 `src/app/` 内；其他找对应成员 |
| 不知道下一步 | 新开会话，让 DSH 先读 `HANDOFF.md` 和合同 |
